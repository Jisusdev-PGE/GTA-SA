# GTA-SA — Pancho Games Studios

A browser-based 3D open-world game inspired by the structure and atmosphere of Grand Theft Auto: San Andreas.

## Current build
- Procedural 3D Los Santos-style city
- Grove Street, Ganton, Idlewood, Willowfield, East Los Santos and Downtown Los Santos
- Third-person on-foot controller
- Drivable vehicles with acceleration, steering and braking
- Traffic and pedestrian simulation
- Wanted level
- Mission/waypoint system
- Day/night cycle
- Minimap/radar
- Health, money and speed HUD
- Original procedural assets — no Rockstar game files are included

## Run
Serve the repository with any local static server (ES modules need HTTP), or deploy it with GitHub Pages.

Example:
python -m http.server 8080

Then open http://localhost:8080/

## Controls
WASD — move / drive
SHIFT — sprint
E — enter/exit nearest vehicle
SPACE — handbrake / brake
MOUSE — camera
ESC — release mouse
R — restart mission

This is an original implementation. Names and fictional locations from San Andreas are used as world references; original Rockstar models, textures, audio and source code are not included.
